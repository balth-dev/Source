# Projet-CDA

## Description
#Description du projet : application de gestion (de bâtiments, d'utilisateurs, d'événements,...)développée en Python avec base de données SQLite/MySQL et interface graphique (Qt ou autre).

## Prérequis
- Python 3.14+
- pipenv ou venv (environnement virtuel)
- Autre dépendance comme bcrypt, SQLAlchemy, pytest...(à retrouver sur requirements.txt)

## Installer les dépendances
pip install -r requirements.txt
